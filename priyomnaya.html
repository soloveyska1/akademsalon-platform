Частые вопросы

Можно без регистрации?+

Да. Для первичной оценки достаточно описания ситуации. Почта нужна только для уведомления об ответе.

Файлы обязательны?+

Нет, но без них редактор сможет дать только общий ориентир. Документы безопаснее передать после первого ответа.

Можно задать вопрос по текущему делу?+

Лучше написать внутри дела: там редактор увидит историю, согласованные решения и документы.
