# Реестр решений

| ID | Статус | Решение | Основание | Триггер пересмотра |
|---|---|---|---|---|
| `DEC-0001` | accepted | «Оттиск» остаётся единой визуальной системой light/dark | Узнаваемость, редакционная серьёзность, подтверждённая консистентность release98 | измеримое непонимание или accessibility-конфликт |
| `DEC-0002` | accepted | Один основной CTA на смысловой экран | Снижает конкуренцию действий и сложность выбора | task test показывает потерю нужного пути |
| `DEC-0003` | accepted | Главный вход — ситуация клиента; каталог является справочником | Клиенту проще назвать состояние, чем выбрать услугу | данные показывают худшую успешность сценария |
| `DEC-0004` | accepted | Модельный совет даёт observations, Codex остаётся единственным write-owner | Исключает конфликтующие правки и «голосование по вкусу» | появится безопасный транзакционный merge-процесс |
| `DEC-0005` | accepted | Second brain хранится в Git и не требует фонового сервиса | Долговечность, diff, backup и нулевая постоянная нагрузка | масштаб данных перестанет помещаться в индексируемые файлы |
| `DEC-0006` | accepted | Успех заявки только после валидного server response и ID | Не допускает ложного подтверждения | никогда, кроме смены API-контракта с эквивалентной гарантией |

Новое долговечное решение получает отдельный `DEC-*`, если существуют реальные
альтернативы, риск или влияние на несколько релизов. Мелкая правка CSS не требует ADR.
