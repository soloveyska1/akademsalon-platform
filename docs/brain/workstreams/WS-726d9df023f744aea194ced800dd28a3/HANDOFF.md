## Две поправки к E-1014, найденные при реализации

1. **Конфигуратор**: утверждение «выхода в остальной сайт с экрана нет» —

2. **Кабинет**: разрыв подтверждён точнее. В залогиненном виде

   `rect 0,104,390,61`, внизу не закреплено ничего.

## Что сделано

Панель разделов кабинета переехала вниз (`position:fixed; bottom:0; z-index:95`,
`padding-bottom:max(5px, env(safe-area-inset-bottom))`, `border-top`). Общий док
остаётся выключенным — решение hall97 не отменяется, нижний слой ровно один,
набор разделов не менялся. Отдельным тестом закреплено, что док не вернётся.

Два следствия переезда закрыты там же:

- панель «Ещё» раскрывается вверх (`top:auto; bottom:calc(100% + 7px)`), иначе
  уходила за нижнюю кромку;
- баннер согласия (`#lrail`, z-index 96) перекрывал панель на 51 px при первом
  визите прямо в кабинет. Уступает баннер: `:root.has-consent-bar
  body.is-account-route .lrail { bottom: calc(var(--account-dock-h) + 8px) }`.
  Прятать панель, как это делает mobile.css для дока, нельзя — в кабинете это
  единственный путь между разделами.
