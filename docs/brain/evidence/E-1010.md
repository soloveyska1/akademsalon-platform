## Reproduced failure and severity

The release102 local/VPS browser matrix reproduced zero visible pointer search
triggers on the home, services and dashboard surfaces from 921 through 1240 px.
Keyboard shortcuts remained available but were not a discoverable substitute.
The same late hide rules exist in release101, so rollback alone does not repair
the gap. This is a P1 reachability failure under G5/G6 and OUT-007.

The first underscoped workstream stopped when full regression exposed required
readiness-test paths outside its declaration. A later v2 workstream stopped when
Brain rejected an attempted canonical merge as stale-base/scope escape. v3 was
generated by `brain workstream init` from exact fresh canonical before replay;
all four test paths and every product consumer were declared first. These stops
are evidence that Brain prevents silent scope escape rather than documenting it
after the fact.

## Bounded implementation

The result preserves search semantics, catalogue IA and the protected OUT-005
inventory. It adds one late global shared-CSS rescue for both public and account
header variants in `assets/css/polish15-chrome.css` for 920–1240 px, rebuilds
only the generated home CSS bundle, and rotates only the shared CSS cache marker
on its exact 89 direct consumers plus the home bundle URL in `index.html`.

Using 920 rather than 921 closes the fractional-pixel seam. At exactly 920 px
the desktop header parent is still hidden by the existing mobile
`max-width:920px` rule, so exactly one mobile trigger remains. Immediately above
920 px the mobile trigger disappears and the rescued desktop trigger is already
active. Above 1240 px the original desktop presentation resumes. The existing
icon-only control remains 44×44 px.

closes the cross-engine and scrollbar P2 raised by Kimi.
