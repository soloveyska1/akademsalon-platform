at x=16..332.5. Body scroll width was 333 while the root clipped it to 320.
The last stage was therefore cut off. The final block uses two bounded columns
below 360 px, preserves the DOM order and adds one internal row separator.

The initial <=340 prototype exposed a second edge: at 341 px the old strip
entered the right gutter by 7.5 px. The final <=359 boundary preserves exactly
16 px on both sides throughout the sub-360 range, without changing >=360.

Independent accessibility review also rejected the first 200% check because
changing only the root font size did not enlarge fixed-pixel text. A real
text-inflation check snapshots each computed font size before doubling it.
This reproduced min-content expansion and an overflowing guide heading.
The final inner column is `minmax(0,1fr)`; stage labels and copy use emergency
wrapping. At 200%, labels remain 22 px and the title 62 px; text reflows rather
than being reduced or clipped.
