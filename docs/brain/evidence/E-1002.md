## Success and stop conditions

Local success for the selected slice:

- every inventoried producer uses one contract helper and no literal bypass;
- identical intent retains one request ID across ambiguous retry/reload;
- changed intent, unavailable durable storage and conflict produce no new network
  send or key rotation;
- success accepts only the canonical response contract;
- deterministic contract tests, generated-bundle parity, full product suite,
  Brain validation and conflict scan are green.

External E2E remains stopped unless server preflight proves marker and cleanup.
Stop on unknown server dedupe/outbox semantics, more than one marker match, a
second order/event/notification, real-client routing, OAuth/deploy need, cleanup
that is not exact and idempotent, or any evidence containing secrets/contact/
client material. Rollback is commit revert; production rollback is not applicable
because this selection authorizes no production mutation.
