## Full September release vetoes

1. Deposit public terms say that spent promotional bonus is not deducted from
   unused cash on refund, while the installed/repository backend subtracts
   `spent_bonus`; the 120,000 RUB cap is not atomically rechecked at activation.
   New activation should fail closed before an atomic contract/runtime redesign.
2. Referral public copy promises one 200 RUB inviter reward after the first
   fully paid order and no invitee reward; runtime implements recurring 5%, a
   200 RUB invitee reward and a 7% refboost. Read-only aggregates found no
   active deposits/refboost rows and no realised referral rewards, so no harmed
   user is asserted. New issuance/refboost still requires a fail-closed gate.
3. `komissiya-0.html` loses the bundle intent in its CTA and does not explain
   the delta above visible component minimums. Salon+ mixes a Pro 10% benefit
   with the Basic `from 449` price; consultation-window entitlements and
   component-refund snapshots are incomplete. Gift presets diverge from the
   server and 2,000 RUB need not buy a complete service.
4. Promo funnel denominators and fulfilment/direct-cost data are absent. The
   existing welcome 12% capped at 5,000 RUB and retention 10% capped at 2,500
   RUB/72h stay unchanged; positive margin is not claimed from caps alone.
5. Confirmed UX debt remains: Browser Back can return forward to Contact after
   the UI Back action, and services/tariffs leak 13px at 320px in WebKit. The
   latter overlaps an active foreign mobile-shell scope and was not edited.
6. `content/legal/LEGAL-READINESS.md` still requires factual confirmation of
   the personal-data notification/cross-border contour, processor and hosting
   terms, tax-receipt path, retention and immutable operational logs. This is a
   release gate for qualified legal/operations review, not a legal conclusion.
7. SEO inventory is structurally healthy for 77 indexable root pages, but all
   77 sitemap `lastmod` values drift from meaningful Git dates, `tools.html`
   lacks a static contextual inbound link, and consent pages carry conflicting
   robots directives. These are follow-ups, not proof of a ranking defect.

contract gates, legal factual confirmations, external smoke and a real static
