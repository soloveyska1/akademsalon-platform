## Implemented local contract

- `nowActionFor()` maps only real non-paused actions to explicit kind, score,
  destination and icon metadata.
- `resolveNowAction()` compares action class first and deadline only inside an
  equal class; exact ties retain input order.
- No-action and unknown-action paths return an empty card. Rendering uses
  explicit action kinds and has no catch-all message branch.
- File/message counters require a numeric value greater than zero.
- Payment classification itself is intentionally unchanged; a broader
  due/claimed reconciliation needs separate server/runtime evidence.
- A council-requested regression case makes the intended same-class behavior
  explicit: an overdue action beats a future action of the same kind; deadline
  never promotes a lower action kind.
- Calm copy no longer claims that the workshop continues work, so it remains
  truthful for a paused case.
- `dashboard.html`, the only HTML consumer of `cabinet.js`, adds
  `priority=truth1` while preserving its existing release and UI keys.
