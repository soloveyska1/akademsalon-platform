## Implemented local contract

- The configurator and guide microlead are the two tracked browser producers;
  a repository-wide guard finds no direct `api.post('/orders')` or literal
  `fetch(...'/orders')` bypass.
- One v2 JSON value binds producer, scope, cryptographic request ID and SHA-256
  intent. Legacy, corrupt, partial, foreign or future state refuses before fetch.
- The fingerprint operates on a JSON round-trip; reordered object keys preserve
  intent while `[]` and `[undefined]` remain distinct wire values.
- Identical concurrent submissions share one physical POST. Soft timeout never
  aborts it, and an immediate retry joins the still-live promise.
- Result states are `confirmed`, `definitive_rejection`, `conflict`, `ambiguous`
  and `local_blocked`. Only the first two authorize an exact-ID CAS clear.
- Positive order IDs are bounded by JavaScript safe-integer semantics, including
  canonical decimal strings.
- Production smoke is an injectable GET/HEAD-only runner. Its unsafe-method guard
  rejects POST before transport; the `/orders` probe has been removed.
- All 90 HTML consumers of the changed shared runtime use cache key
  `20260802out001submit1`; the rebuilt home JS bundle contains the same contract.
