## Reproduced P1

1. Choice/state hierarchy. At 390×844 with a real saved local draft,
   `services.html` shows an inline 44 px “Продолжить”, four 108 px situation
   routes and a second dock continuation in the same viewport. At 1440×900 the
   resume action, four routes, four filters and search are all present before or
   at the fold. There is no single selected situation plus continuation state.
2. Conflict focus/history. Opening a new route with saved progress shows two
   honest outcomes, but after “Начать заново” active focus becomes `BODY`.
   `situation/result/route` are removed before conflict resolution; reload on
   the conflict screen loses the incoming choice and silently returns to the
   old wizard state.
3. Dark contrast. Browser computed styles on page-owned controls measured:
   services primary `#fffaf3/#ff6b4b` 2.712:1; saved-progress action
   `#fff9f1/#ff6b4b` 2.692:1; representative service detail primary
   `#fffaf3/#c65b41` 4.065:1. Normal-size text requires 4.5:1. The existing dark
   deep token `#A4432D` gives about 5.914:1.
4. Detail intent truth. Fourteen of 22 detail pages contain bare
   `href="configurator.html"` hero/action routes and depend on localStorage.
   `storeDraft()` can mutate legacy `draft.state` while preserving a stale,
   higher-precedence `draft.concept`; the new service choice can therefore open
   an old work/result. Several pages also disagree with `pageCaseContext()` or
   card wording, notably candidate dissertation, practice report, practice
   rework and referat. Price/copy truth must be reconciled, not guessed.

## Browser-safe experiment resolving the model fork

The default configurator already derives the exact same result mapping from a
situation even when the URL omits `result`: topic→diagnostic, draft→editing,
comments→diagnostic, defense→defense. An explicit local prototype using
`?situation=comments&result=diagnostic&route=page` did not change the offer; it
activated the existing compact presentation, said the situation was already
chosen, asked one work question, then showed “Разбор замечаний” and one 50 px
“Указать срок” action. Therefore the mapping is allowed only with exact tests
that prove semantic equality and reject incompatible/free-text route state.

Across 360/390/768/1024/1440, light/dark, the current services surface had
overflow 0, 44 px filter/search targets, 108–161 px situation targets, visible
focus and no console warning/error. Reduced motion is source-guarded but was not
browser-emulated.
