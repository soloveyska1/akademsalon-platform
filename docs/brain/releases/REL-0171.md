## Candidate outcome

The branded welcome artwork is now a 33,652-byte versioned WebP with the exact
existing PNG as an executable fallback. Gated users do not request either
image. A browser-discovered eligibility boundary was closed so a returning
local footprint suppresses welcome even when the server still says
`eligible`; owner preview remains a labelled, non-redeemable presentation.

Application entry and terminal copy now reflect the actual three-step route,
allow no-file applications, use one conditional response window and avoid
promising an exact price before enough information exists. Prices, welcome and
retention percentages/caps, 72-hour retention duration, best-of/25% limits,
backend eligibility and submit semantics are unchanged.
