# Акция «11.11 в последний момент» (11 и 12 ноября 2026)

11.11.2026 вечером владелец одобрил запуск и выкладку двух вещей: страницы акции
`11-11.html` и тонкой плашки на главной. Больше на сайте ничего не меняется.

Суть акции: новые заказы ВКР и курсовых с предоплатой до 23:59 12 ноября по Москве получают
к защите презентацию, речь и нормоконтроль бесплатно (отдельно 9 500 ₽), мест 11.
Текст страницы и плашки дословно из брифа владельца, добавлены только неразрывные пробелы.

## Файлы

- `11-11.html` — страница целиком, в таком виде она лежит на сайте. Оболочка взята байт в байт
  с `gift.html` живого release273 (head со всеми ассетами, тема, шапка, подвал, скрипты согласия
  и аналитики). Заменены только `title`, `description`, `canonical`, og/twitter-теги
  (`og:image:alt` = «Академический Салон», без тире), `robots` = `noindex` (акция на двое суток,
  в `sitemap.xml` страницы нет), добавлен `<style>` страницы в конце head и свой `<main>`.
  Типографика как на `reviews.html`: текст Golos Text, вторая строка заголовка Literata курсивом,
  цвета из токенов ds-v4 (`--ds-violet`, `--ds-violet-soft`, `--ds-paper`), фон страницы кремовый
  из оболочки. Выделенная строка «Мест всего 11…» подчёркнута лаймовым маркером, как пункты меню
  в шапке (в тёмной теме маркер сиреневый: лаймовый на тёмном выглядел грязно-оливковым).
  Кнопки: «Написать Семёну в Telegram» → `https://t.me/Thisissaymoon?text=11.11` (личный аккаунт
  Семёна; @academicsaloon в тексте страницы нет, в общей шапке остался как на всех страницах),
  «Оформить заявку» → `configurator.html`, как «Заказать работу» в шапке.
- `ribbon.py` — вставка плашки в `index.html` и `home-v4.html` (обе версии главной).
  Идемпотентна: старая плашка снимается по меткам `<!-- promo-1111 -->…<!-- /promo-1111 -->`,
  повторный прогон даёт те же байты, `--remove` возвращает файлы байт в байт к исходным.

```bash
python ribbon.py <папка с HTML живого релиза> <куда писать>            # вставить
python ribbon.py <папка с HTML живого релиза> <куда писать> --remove   # убрать после акции
```

Плашка стоит сразу после ссылки «К содержанию», то есть перед липкой шапкой: уезжает при
прокрутке, шапка прилипает как раньше (проверено: `top` шапки 53 → 0 px на телефоне).
Вся строка — одна ссылка на `11-11.html`, на телефоне 375/360/320 px две строки, на десктопе одна.
Позиция и z-index обычные: открытое меню (диалог) её закрывает. В `.hv-voice` она не попадает,
`home-v4.js` её не трогает.

## После 23:59:59 12 ноября (МСК)

Обе вещи сравнивают `Date.now()` с `Date.parse('2026-11-12T23:59:59+03:00')` маленьким инлайн-скриптом:

- на странице вместо лида и условий показывается «Акция закончилась 12 ноября в 23:59…»
  и две кнопки: Telegram без `?text` (`https://t.me/Thisissaymoon`) и «Оформить заявку»;
- плашка на главной удаляет себя до отрисовки.

Без JS страница показывает предложение, плашка остаётся. Закрыть раньше срока (кончились
места): поменять дату в `11-11.html` и в `ribbon.py` (`END`) на прошедшую и выложить новым
релизом. Убрать плашку физически после акции: `ribbon.py --remove` и релиз.

Сервис-воркер (`sw.js`, `seo-20260911-v1`) разметку берёт из сети первой (network-first,
кэш только на случай офлайна), nginx отдаёт HTML с `no-cache, must-revalidate`, новых ассетов
нет: плашка и страница видны сразу после выкладки, `sw.js` не менялся.
