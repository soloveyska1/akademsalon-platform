## Как устроено

- Поиск, темы, «Сохранённое», маршрут, оглавление и прогресс по-прежнему делает `salon-library.js`, размер и
  интервал текста — `salon-ease.js`, «Поделиться», «Разделы», «Только читать» и окна — `salon-reading.js`.
  Разметка хаба держит все их data-атрибуты; скрипты не менялись.
- `library-v4.js` подключается после них. Он снимает стрелки (↗ ↓ ↑ ←) с подписей, которые пишут эти скрипты
  («Ещё 9 материалов ↓», «Поделиться ↗», «Разделы ↑»): в кнопках сайта стрелок нет. Подписи перерисовываются,
  поэтому за ними следит MutationObserver — только внутри `main`, окон и панели «Только читать», значки шапки
  и Листика он не трогает. Ещё он ведёт подсказку поиска на хабе и делает чек-листы.
- Старый сайт красит `h1–h3` и `p` напрямую, стилизует все `input` и даёт `label` отступы, а `discovery.css`
  задаёт блоку `.gd-related` всё через `!important`. `library-v4.css` это сбрасывает; все правила начинаются
  с `body.salon-learning.ds-v4`. Переменные `--sx-*` из `salon-reading.css` переназначены на токены `ds-v4`,
  поэтому окна читалки в той же палитре, в том числе в тёмной теме.
- `build_library_v4.py <папка с прежними страницами> <out> [--preview]`. Хаб — новый `<main>`: карточки, темы
  и маршрут берутся из прежней страницы, JSON маршрута не меняется. Разборы — подписи без капслока и стрелок,
  подключение `ds-v4.css`, `library-v4.css`, `library-v4.js` и класс `ds-v4`. У всех убран призыв в подвале.
  С `--preview` — `*-v4.html` с noindex, ссылки раздела ведут на превью. В `src/` — прежние страницы из release257;
  сборка воспроизводит живые страницы (и превью) байт в байт. Версия стилей и скрипта — `library-v4-20261030-1`.

```bash
python build_library_v4.py src out
```
