# «Примеры работ» v4

30.10.2026, по просьбе владельца: «раздел примеры надо переделать, чтобы было стильно, современно,
удобно, красиво, информативно». Стиль — `ds-v4`, как у главной, шапки, «Работ и цен» и формы заявки.

## Что сделано

- Первый экран — ночная сцена: «Примеры работ» антиквой, факты на плашках с лаймовыми значками
  (7 работ, 274 страницы, копии обезличены), «Смотреть работы» и Telegram. Справа веер из семи
  настоящих страниц, по одной от каждой работы; одно движение при загрузке — веер раскрывается
  (при `prefers-reduced-motion` его нет).
- Все семь работ видны сразу. Раньше их открывали по одной через переключатель типов, теперь это сетка
  карточек: курсовая на всю ширину, с описанием, что внутри (сверено с PDF), остальные — три в ряд.
  В карточке тип, число страниц, направление, чипы-переходы («Введение с. 2», «Таблицы с. 46»),
  «Читать целиком» и «Заказать такую» с ценой «от …» из каталога сайта.
- «На что смотреть в примере» — аннотированное оглавление магистерской (`project`). Каждая строка
  открывает свою страницу: введение (с. 3), выводы по главе 1 (25), таблица 2.1 (31), рисунок 2.1 (36),
  заключение (99), список из 107 источников (102). Номера страниц и подписи сверены с PDF.
- «Образцы разделов» — три PDF из `assets/samples/` (введение ВКР, аналитический параграф, список по
  ГОСТ) в той же читалке и по ссылкам «Поделиться».
- Читалка перекрашена в v4 (шрифты, кнопки 40 px, чипы, фиолетовая «Заказать такую работу»). Если
  работу уже читали, кнопка показывает «Продолжить со стр. N» (закладки — `SalonReturn`).
- Призыв «Теперь к твоей задаче» из подвала убран: его заменяет финальный блок страницы (как на главной).
- Телефон: карточки в строку (лист слева, кнопки на всю ширину), образцы — тоже в строку, Листик —
  только маскот, как на главной.

## Как устроено

- Читалка прежняя — `salon-portfolio.js` (pdf.js, поиск, миниатюры, закладки, `#pdf=<id>&page=<n>`).
  Сборщик добавляет в её конец одну строку `window.SalonPortfolioReader={open:open}` и склонение
  «страница/страницы/страниц» в подписи. Скрытый блок прежней библиотеки (`#library-types`,
  `#library-variants`, `#library-document`) остаётся в разметке: скрипт без него не запускается.
- `samples-v4-data.js` (после `salon-portfolio-data.js`) добавляет в `window.SalonPortfolio` три образца
  разделов, поэтому они открываются в читалке и по прямым ссылкам. `samples-v4.js`: клик по
  `[data-open]` (с `data-page` — сразу на странице), цены из `SalonProducts`, «Продолжить со стр. N»,
  цели Метрики `tg_click_<data-tg-cta>` (как `home-v4.js`). Без JavaScript ссылки ведут на PDF.
- `samples-v4.css?v=samples-v4-20261030-1` — все правила с `body.salon-portfolio.ds-v4`.
- `build_samples_v4.py <samples.html релиза> <salon-portfolio-data.js> <salon-portfolio.js>
  <salon-products.js> <out> [--preview]` пишет `samples.html` (или `samples-v4.html` с noindex) и
  пропатченный `assets/js/salon-portfolio.js`. На вход — исходный, ещё не пропатченный
  `salon-portfolio.js` (sha 1db10376…); проверки внутри падают, если разметка релиза разошлась.
- `make_sample_images.py <папка с assets/samples> <out>` — `img/`: обложки семи работ и первые страницы
  трёх образцов, WebP 480 px (на сайте — `assets/img/samples-v4/`).

## Проверено

Локально поверх живого сайта и на проде: 1440, 1024, 820 и 390 px, тёмная тема — на 1440. Карточки,
чипы, строки оглавления и образцы открывают читалку на нужной странице; фокус после закрытия
возвращается на кнопку; старые ссылки `samples.html#pdf=method&page=12` и ссылки на образцы
открываются; «Продолжить со стр. 7» после чтения и возврат на ту же страницу; цены совпадают
с каталогом; горизонтальной прокрутки нет; ошибок в консоли нет. Старая страница с пропатченной
читалкой тоже открывала документы. Не измерено: влияние на заявки.
