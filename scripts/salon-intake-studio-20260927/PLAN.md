# Intake studio plan

Subject: a student handing an academic task to the Salon. The page has one job: convey the task and a usable contact, then request an agreed estimate. Scope is the form area shown by the owner, not a new checkout or price model.

Pass one: compare a long flat form with a small writing desk. The desk keeps the task editor as paper, makes contact selection explicit, places optional name beside contact, and folds codes into a separate labelled disclosure. Consent becomes readable clickable rows. Reuse Golos Text for readable inputs/labels, existing Literata only in the unchanged page heading, JetBrains Mono for short utility captions. Theme roles: sheet #ffffff, paper #f7f7fb, ink #272238, muted #645e73, accent #5140c9, soft #eee9ff; all read existing CSS variables including dark equivalents.

Pass two critique: no dashboard progress score, invented urgency or gratuitous full-screen wizard. Useful additions are specific to this task: insert an empty requirement heading without overwriting prose; focus an existing heading instead of duplicating it; undo only the untouched insertion; recognize completed contact formats without changing the value; show entered-code count without claiming a discount. Contact choices form the single visual signature: compact icon tiles with Salon's paper-tab selected corner. Everything else is a quiet readable form.

Preserve exact inputs, limits, validation, consent text/links, unchecked state, serialized payload, retry freeze and success rules. No new persistence, telemetry or network requests. Test both themes,319–1440, keyboard, long copy, optional states, synthetic accepted/rejected/uncertain submissions and upload/date regressions. Two independent reviewers and root own screenshots must confirm the final artifact.
