# Services clarity design plan

Subject: academic-service selection for a student who needs a specific result and a credible preliminary cost. Page job: choose the task, understand scope and optional costs, carry that exact choice into the request.

Pass1. Alternatives:
A: cosmetic fix to the missing whitespace: [old hero][old catalogue][fixed headline]. Rejected because it leaves undisclosed VIP cost, tiny secondary copy and disconnected selected-state cues.
B: quiet task desk: [short title + real3-step route][compact situations][clear work list | selected result and price][separated benefits][questions]. Selected. A readable receipt for the exact chosen task is the signature, not a large decorative slogan.

Tokens: background #f7f7fb, surface #ffffff, ink #272238, muted #645e73, accent #5140c9, soft #eee9ff; success uses existing #37552a on #e4efdb. Dark role equivalents retained. Display: Literata regular only for the standalone page title; no mixed-face section headings. Body and control: Golos Text with normal tracking; utility captions use restrained JetBrains Mono. No cursive concatenation, no decorative prose broken with CSS-hidden br.

Pass2 critique: retain recognisable Salon violet but cut the huge solid promotional rectangle and monogram. Spend prominence on the selected task, amount and explicit optional costs. Increase body/helper type and remove shared label/section margins that create accidental gaps. Use explicit named states instead of silently resetting custom selections. Reduce required reading: short masthead, compact situation controls, saved choice above rows, per-service purpose and selected-result description, visible VIP delta, clear benefit action. Benefits use concrete titles, separated surfaces and existing terms; no invented discounts.
