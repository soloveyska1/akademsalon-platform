# Семь новых отзывов (сентябрь — октябрь 2026)

30.10.2026, владелец прислал семь скриншотов переписки из Telegram с просьбой «В отзывы».

## Что сделано

- `prepare_reviews.py <папка со скриншотами> <out>` — как у остальных отзывов: аватарки в реакциях
  запикселены (отзывы 51 и 52), обрывки соседних сообщений сверху срезаны (51, 53, 57), по пикселю
  рамки окна с краёв. Обращение к мастеру по имени оставлено, как в остальных скриншотах.
  Сохраняет полный WebP и миниатюру шириной 420 px. Исходные PNG в репозиторий не кладём: на них
  аватарки без пикселизации.
- `img/` — готовые `review-51…57.webp` и `thumbs/` (на сайте — `assets/img/reviews/`).
- `add_reviews.py <папка с HTML релиза> <out>` ставит семь карточек первыми на `reviews.html` (та же
  разметка `rv-card`, подписи — слова клиентов) и меняет на главной «47 сообщений» и «47 отзывов» на
  «54 сообщения» и «54 отзыва» (`index.html`, превью `home-v4.html`). Счётчик на странице отзывов
  скрипт сайта считает сам. В исходнике главной (`scripts/salon-home-v4-20261030/main.html`) число
  поправлено так же: сборка главной (`build_home_v4.py` → `apply_ds_shell.py` → `apply_header_v4.py`)
  воспроизводит живой `index.html` байт в байт.
