# Шапка v4: маркер, Telegram и ночное меню

30.10.2026, по просьбе владельца: «шапку переработай полностью… должно быть оч красиво и удобно,
современно, в нашем стиле». Стиль — дизайн-система `ds-v4` (`scripts/salon-home-v4-20261030/DESIGN.md`).

## Что сделано

- Полоса стала ниже (76 px на ПК, 64 px на телефоне), полупрозрачная с размытием. Разделы набраны
  Onest 15 px, текущий выделен лаймовым маркером — как пометки на страницах работ на главной;
  при наведении маркер прорисовывается слева направо.
- Справа: поиск, кабинет, Telegram (лаймовая круглая кнопка, `data-tg-cta="header"`), «Заказать
  работу», «Меню». До 1190 px разделы уходят в меню, кабинет становится иконкой; до 800 px в шапке
  остаются поиск, Telegram и меню — Telegram в один тап с любой страницы.
- Меню (`dialog` из `salon-shell.js`) — ночная сцена: «Найди своё.», поиск, ссылки 17 px, подписи
  групп без капслока, лаймовая карточка «Целиком. По частям. Как тебе нужно.» с «Собрать заказ» и
  «Написать в Telegram» (`data-tg-cta="menu"`). На телефоне заказ стоит лаймовой кнопкой наверху меню,
  а карточка ведёт в Telegram. Встроенные блоки «Недавно смотрел» и «Вид сайта» перекрашены через
  их же переменные (`--ink`, `--line`, `--accent` и др.), у меню `color-scheme: dark`.
- В тёмной теме сайта полоса берёт цвета из `--sh-*`, поэтому перестраивается сама.

## Как устроено

- `ds-header.css` — только вид. Подключается сразу после `ds-shell.css`; селекторы начинаются с
  `html`, чтобы перебить старые правила `salon-experience.css` без `!important`.
- `apply_header_v4.py <папка> [файлы]` правит разметку общей шапки: кнопка Telegram, подписи меню без
  капслока, Telegram в карточке меню, ссылка на `ds-header.css?v=ds-header-20261030-1`. Ссылки
  «Заказать» на страницах видов работ не трогает. Повторный запуск ничего не меняет; страницы без
  шапки (`404`, `50x`, `admin*`, `dashboard`, `maintenance`, `offline`, `zero-classes`) пропускает.
- `salon-shell.js` и `salon-experience.js` не менялись: хуки `.sh-menu`, `.sh-panel`,
  `[data-sh-close]`, `.sh-order`, `.sh-mobile-order`, `.sh-start-order`, `.search-button` на месте.
- `tools/cdp_shots2.mjs <папка> <профиль Chrome> <список.json>` — скриншоты по списку через
  DevTools-протокол: честная ширина телефона, тёмная тема, клик перед снимком (например, открыть меню).
