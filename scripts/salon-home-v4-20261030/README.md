## Как собрано

- `build_home_v4.py <index release230> main.html <out>`. Вход —
  `/var/www/academic_saloon/releases/release230-tg-5bbfac4d/index.html` с диска сервера, не ответ
  nginx (`sub_filter` дописывает в отдаваемый HTML `/6let-ribbon.js`). Скрипт заменяет `<main>`,
  убирает дубль призыва из подвала, вместо `home-trust` подключает прелоад двух кириллических
  шрифтов, `ds-v4.css`, `home-v4.css`, `home-v4.js` с `?v=home-v4-20261030-4` и вешает на `<body>`
  класс `ds-v4`. `salon-home.js` и `salon-select.js/css` с главной убраны: калькулятор свой.
  Сборка воспроизводит live `index.html` байт в байт (sha256 `4c795839e265…`).
- Раскладка в релизе: `assets/css/ds-v4.css`, `assets/css/home-v4.css`, `assets/js/home-v4.js`,
  `assets/fonts/v4/*.woff2` (здесь `fonts/`), `assets/img/home-v4/*.webp` (здесь `img/`).
- Сервис-воркер сайта отдаёт ассеты с `?v=` из кэша: после любой правки CSS или JS поднимать `VER`.
- `tools/preview_proxy.py <папка> <порт>` — локальное превью: свои файлы поверх живого сайта,
  только GET/HEAD. `tools/cdp_shots.mjs <папка> <url> <профиль>` — скриншоты телефона через
  DevTools-протокол (Node 24, без зависимостей). Headless `--screenshot` для телефона не годится:
  окно не уже ~500 px, а с `--virtual-time-budget` Chrome виснет на сервис-воркере.

## Шрифты и картинки

- Literata Display (заголовки) и Onest (текст) — SIL OFL 1.1, взяты через Google Fonts CSS2 API
  и лежат у себя: CSP сайта `font-src 'self' data:`. Подмножества: кириллица, латиница,
  latin-ext (знак ₽ у Onest — в latin-ext). Курсив в подписях — Literata из базовых шрифтов сайта.
- `img/listik-*.webp` вырезаны из спрайта виджета `assets/img/salon-assistant/listik-states.webp`.
  `page-*` и `sample-*` — те же обезличенные образцы, что в v2 (см. её README).

## Калькулятор «Что нужно сделать?»

- Шаги: работа (цены прямо на плашках, редкие работы под «Другие работы»), объём (целиком,
  часть, доработка), направление, срок (не срочно, 2–4 недели +15%, до 2 недель +45%, за сутки ×2),
  дополнения под «Добавить к работе» (презентация и речь, нормоконтроль, «разобраться в работе»; пакет
  к защите дешевле на 1 500 ₽).
- Цена — `SalonCalc.quote`: тариф vip для «Целиком», turn для «Доработки». «Часть», введение,
  правки и нестандартные задачи показывают «Назовём по заданию». Ограничения: введение — только
  часть, правки — только доработка, глава — часть или доработка, у кандидатской нет «за сутки».
- «Отправить расчёт в Telegram» открывает `t.me/academicsaloon?text=` с работой, направлением,
  сроком, дополнениями и ориентиром. «Оформить заявку на сайте» открывает
  `configurator.html?composition=1` с этим составом. Состав пишется в sessionStorage
  (`salon_composition_v1`, `salon_direct_selection_v1`, `salon_home_term_v4`) только после
  действия человека — иначе на главной всплывала полоса «Вы выбирали».
- На телефоне плашки в две колонки, пузырь Листика прячется, пока калькулятор на экране.
- Цели Метрики (только при согласии на аналитику): `tg_click_{hero,calc,calc_note,faq,final,bar,footer}`,
  `calc_order_click`, `review_open_home`. Все `tg_click_*` попадают в цель «Посещение Telegram»
  (условие «содержит tg_click»); отдельные цели есть для hero, bar, final и dock. Отдельных целей
  на `tg_click_calc` и `calc_order_click` в Метрике нет.

## Проверено

Локальное превью и превью на проде: 375, 390, 820, 1100 и 1440 px, светлая и тёмная темы, нет
горизонтального скролла, ошибок в консоли нет. Цены сверены с формулами: диплом + психология до
2 недель — 70 000 ₽, с пакетом к защите — 79 500 ₽, за сутки — 106 500 ₽; магистерская +
юриспруденция за 2–4 недели с презентацией — 75 000 ₽. Текст для Telegram, передача состава в
конфигуратор (диплом, психология, презентация → «54 500–74 000 ₽»), сохранение выбора только
после действия. После включения: `/` отдаёт v4, `robots index,follow`, canonical `/`, HTML с
`Cache-Control: no-cache`, ассеты и шрифты 200 с верными типами, хэши совпадают с исходниками.

## Открыто

- Шапка и меню сайта пока на Manrope, виджет Листика — на Golos. Переводить их на `ds-v4` вместе
  с остальными страницами, иначе шапка будет меняться при переходе между страницами.

  конфигуратор показывает плановый срок без надбавки.
- Рост конверсии не измерен.
