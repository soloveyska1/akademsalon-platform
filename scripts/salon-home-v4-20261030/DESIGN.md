# Дизайн-система ds-v4

Действует внутри `body.ds-v4` (пока только главная v4). Чтобы перевести страницу: класс `ds-v4` на `<body>`, подключить `assets/css/ds-v4.css`, блоки страницы — своим файлом с собственным префиксом.

## Шрифты

| Роль | Шрифт | Токен / классы |
|---|---|---|
| Заголовки | Literata Display, 400–600, оптический размер 36–72 | `var(--display)`, `.ds-display-1`, `.ds-display-2` |
| Текст и интерфейс | Onest, 400–700 | `var(--sans)` |
| Курсивные акценты (подписи отзывов, пометки на страницах) | Literata italic из базовых шрифтов сайта | `var(--serif)` |

Оболочка сайта (шапка, меню, поиск, Листик) на Onest на всех страницах через `ds-shell.css` (`scripts/salon-ds-shell-20261030/`).

Файлы свои — `assets/fonts/v4/*.woff2`, разбиты по unicode-range (кириллица, латиница, latin-ext): CSP сайта разрешает шрифты только с `'self'`. Кириллические файлы обоих шрифтов прелоадятся в `<head>`.

## Цвета и формы

Токены объявлены на `body.ds-v4.salon-experience`, тёмная тема переопределяет их на `:root[data-theme=dark]`.

- Текст: `--ds-ink`, `--ds-muted`. Линии: `--ds-line`, `--ds-line-2`.
- Поверхности: `--ds-paper` (карточка), `--ds-mist` / `--ds-mist-2` (лавандовые подложки), `--ds-card` (чипы).
- Действие и выбор: `--ds-violet` (+ `-hover`, `-soft`, `--ds-on-violet`).
- Главная кнопка на тёмной сцене: `--ds-lime` (+ `-hover`, `--ds-lime-ink`).
- Ночная сцена: `--ds-night`, `--ds-on-night`, `-2`, `-3`, `--ds-night-line`.
- Тени `--ds-shadow-1/2`, радиусы `--ds-radius-s/m/l` = 12/18/28.

Правила: фиолетовый — только действие и выбранное состояние; лайм — одна главная кнопка на тёмной сцене (Telegram); тёмных сцен `.ds-night` на странице не больше трёх (первый экран, калькулятор, финал).

## Компоненты

- `.ds-btn` + `--lime | --violet | --ghost | --line | --block` — высота 56.
- `.ds-link` — подчёркнутая ссылка, зона нажатия 44 px.
- `.ds-ico` — иконка 24 px в плашке 48.
- `.ds-night` — тёмная сцена с подсветкой и тетрадной клеткой; `.ds-panel` — лавандовая панель.
- Выбор: `<label class="ds-choice"><input type="radio|checkbox"><span class="ds-chip">Текст<small>подпись</small></span></label>`. Сегментный переключатель — те же чипы в обёртке `.ds-seg`. Настоящий input растянут на всю площадь (opacity 0): работают клавиатура, скринридер и тап.
- Текст: `.ds-display-1`, `.ds-display-2`, `.ds-title`, `.ds-lead`, `.ds-text`, `.ds-small`, `.ds-num` (табличные цифры), `.ds-sr` (только для скринридера).

## Ловушки сайта

- Глобальные правила `salon-direct.css` протекают внутрь: `label{display:block;margin:20px 0 8px}`, `fieldset{background:var(--sheet);border-radius:20px;padding:30px}`, `summary{padding:19px 0}`. В ds-v4 их сбрасывать (сделано для `.ds-choice`, `.calc-row`, `summary` калькулятора).
- Занятые классы: `.hp` — honeypot формы, `.sa-*` — виджет Листика. Блоки главной — префикс `hv-`.
- Сервис-воркер отдаёт ассеты с `?v=` из кэша: после правки CSS или JS повышать `VER` в `build_home_v4.py`.
- Полоса `.selection-trail` на главной скрыта — калькулятор сам показывает выбор.
- На телефоне пузырь Листика прячется, пока калькулятор на экране (`body.hv-calc-focus`).

## Калькулятор «Что нужно сделать?»

Шаги: Работа → Объём → Направление → Когда сдавать → Добавить к работе. Цена — `SalonCalc.quote` (тариф vip для «Целиком», turn для «Доработки»); «Часть», правки и нестандартные задачи показывают «Назовём по заданию». Дополнения и пакет «к защите» — из `SalonCommerce`.

Выбор пишется в sessionStorage (`salon_composition_v1`, `salon_direct_selection_v1`, `salon_home_term_v4`) только после действия человека. «Оформить заявку на сайте» открывает `configurator.html?composition=1` с этим составом. «Отправить расчёт в Telegram» открывает `t.me/academicsaloon?text=` с готовым текстом: работа, направление, срок, дополнения, ориентир.

Цифра цены доезжает анимацией 320 мс; при `prefers-reduced-motion` и в фоновой вкладке — сразу, а таймер страхует, если кадры не идут.
