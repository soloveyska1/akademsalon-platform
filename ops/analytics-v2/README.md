# Analytics v2 — выпуск и откат

## Граница данных

- Новая серия начинается с момента выпуска и не смешивается с legacy.
- «Посетитель» означает случайный браузерный идентификатор после согласия.
- IP и полная строка браузера используются только в памяти для определения
  приблизительного региона и безопасных категорий; в таблицы v2 не записываются.
- Контакт, имя, номер заказа, аккаунт, query/hash, поля, тексты, файлы и OAuth
  не входят в схему, API или панель.
- DB-IP City Lite используется локально по лицензии CC BY 4.0; в интерфейсе
  сохраняется атрибуция источника геоданных.

## Порядок выпуска

1. Повторить `git fetch origin`, conflicts и все quality gates на точном SHA.
2. Собрать неизменяемый static release и backend bundle с SHA-256 manifest.
3. На VPS проверить source/runtime hashes и свободное место.
4. Installer создаёт SQLite Online Backup API copy с `integrity_check=ok`,
   копии `webapp.py`, `db.py` и Nginx-файлов. Временную копию БД отдельно
   открыть и прогнать schema/ingest/readback/revoke smoke.
5. Установить `maxminddb` в существующий venv и локальную DB-IP City Lite MMDB;
   сетевой адрес не отправлять в геосервис.
6. Создать отдельный секрет подписи длиной не менее 32 случайных символов в
   root-only EnvironmentFile systemd (`chmod 600`), передать его как
   `ANALYTICS_SIGNING_SECRET` и не выводить значение в лог или evidence.
7. Установить модуль, контракт и integration seams. Затем `nginx -t`,
   синтаксическая проверка Python и однократный restart сервиса.
8. Выпустить статический release атомарной сменой `current` symlink.
9. Отправить синтетический consented набор `view → CTA → input → attempt →
   success`, повторить те же `event_id` и проверить exact accepted/duplicate.
10. Проверить панель на 390/1024/1440, затем revoke тестового посетителя и
   подтвердить нулевой остаток raw rows. Не использовать контакт или заказ.
11. Проверить health, ключевой клиентский путь, CSP, фоновую retention-задачу
    и отсутствие запросов до согласия. Сохранить точные SHA, counts и backup
    path в `E-1015`.

## Откат

- Вернуть предыдущий static symlink.
- Запустить installer с `--rollback <точный backup dir>`, затем `nginx -t` и
  restart сервиса.
- Таблицы v2 на горячую не удалять: они аддитивны и не влияют на legacy.
- SQLite backup восстанавливать только при доказанной порче данных, после
  остановки сервиса и отдельной копии текущего файла/WAL.
