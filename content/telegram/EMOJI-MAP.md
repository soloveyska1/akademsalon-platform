# Фирменный набор эмодзи

Набор собран из уже опубликованных сообщений `@akademsalon`, а не придуман заново.

## Роли

| Эмодзи | Роль в тексте | Частота |
|---|---|---|
| 🤩 | фирменный вход, сильный вывод, мягкий CTA | 1–2 на пост |
| ☁️ | спокойный маркер списка | 3–5 в одном блоке |
| 🔤 | нумерованные или смысловые шаги | 2–4 в одном блоке |
| 📚 | библиотека, гайд, статья, подборка | 1 |
| 🧮 | расчёт стоимости, смета | только кнопка |
| 📖 | читать статью или открыть памятку | только кнопка |
| 🔍 | проверка, разбор, диагностика | 1 или кнопка |
| 🛩 | связь с человеком | только CTA |

## Правила

- Не ставить эмодзи в каждом абзаце: фирменный стиль держится на ритме, а не на конфетти.
- `🤩` не повторять у каждого пункта. Это «печать мастерской», а не буллет.
- В одном списке использовать один тип маркеров: либо `☁️`, либо `🔤`.
- Не смешивать больше трёх семейств эмодзи в одном посте.
- Для деловых и тревожных тем избегать случайных огней, сирен, денег и кричащих смайлов.

При автоматической публикации сначала отправить тест в закрытый канал и проверить, что бот имеет право использовать выбранный custom emoji.
