# Контент-пакет «Академического Салона»

Готовый комплект для двух связанных редакционных продуктов:

- публичного Telegram-канала `@akademsalon`;
- закрытой подписной «Полки Академического Салона».

## Что внутри

- [CONTENT-PACK.md](./CONTENT-PACK.md) — выводы по каналу, голос бренда, Telegram-функции, 12 готовых публикаций и сетка на 14 дней.
- [EMOJI-MAP.md](./EMOJI-MAP.md) — фирменный набор эмодзи и технические ID уже использованных анимированных эмодзи.
- [01-kak-nauchruk-chitaet-rabotu.md](./articles/01-kak-nauchruk-chitaet-rabotu.md) — готовая статья для Telegraph.
- [02-dedlain-sryvaetsya-ne-na-tekste.md](./articles/02-dedlain-sryvaetsya-ne-na-tekste.md) — готовая статья для Telegraph.
- [03-perevodchik-s-nauchrukovskogo.md](./articles/03-perevodchik-s-nauchrukovskogo.md) — готовая статья для Telegraph.
- [reel-01-metodichka-6-strok.mp4](./motion/reel-01-metodichka-6-strok.mp4) — вертикальный ролик 20 секунд.
- [reel-02-kak-chitayut-7-minut.mp4](./motion/reel-02-kak-chitayut-7-minut.mp4) — вертикальный ролик 22 секунды.
- [reel-03-perevodchik-nauchruka.mp4](./motion/reel-03-perevodchik-nauchruka.mp4) — вертикальный ролик 20 секунд.
- [shelf/README.md](./shelf/README.md) — отдельный премиальный пакет «Полки»: стратегия, посты, статьи, рабочая тетрадь и видео.

Статичные эксперименты с бумагой сохранены только как черновые исходники и не входят в рекомендованную публикационную линейку.

## Статус

Материалы подготовлены, но ничего не опубликовано. Перед публикацией нужно:

1. создать три Telegraph-страницы из готовых статей;
2. выбрать фирменные анимированные эмодзи из сохранённых сообщений либо передать их ID боту;
3. подтвердить следующий календарь публикаций.
